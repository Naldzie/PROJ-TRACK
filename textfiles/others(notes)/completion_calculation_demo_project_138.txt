  Effective Position = month_index_of_lower + fraction
  Effective Position = 6 + 0.1333
  Effective Position = 6.13

================================================================================
  WHY NOT JUST POLYNOMIAL EXTRAPOLATION? (COMPARISON)
================================================================================

  If we had used pure polynomial extrapolation (solving ax³+bx²+cx+d=100):

    Equation: y = -0.0385x³ + 1.0589x² - 2.4784x + 2.7000
    Solve for y = 100:  x ≈ 11.2 (using Newton-Raphson)

    Predicted completion: Month 11.2 (November 2025)
    Delay: -11 days (AHEAD of schedule)

  This is OVER-OPTIMISTIC because the polynomial sees the current
  acceleration phase and projects it forward, ignoring that projects
  inevitably decelerate near completion.

  ┌───────────────────────────────────────────────────────────────┐
  │  Method                  │ Est. Completion │ Delay    │ Trust? │
  ├───────────────────────────┼─────────────────┼──────────┼────────┤
  │ Schedule-Aware (USED)    │ Feb 26, 2026    │ +57 days │ ✅ Yes │
  │ Polynomial Extrapolation │ Nov 20, 2025    │ -11 days │ ❌ No  │
  │ (Newton-Raphson)         │ (ahead!)        │          │        │
  └───────────────────────────────────────────────────────────────┘

  WHY THE DIFFERENCE?
    • Schedule-aware: "You are actually behind (lag = 1.87 months).
      Your completion date shifts by 1.87 months." → Conservative ✓
    • Polynomial solve: "You just accelerated, so we assume you'll
      keep accelerating to completion." → Over-optimistic ✗
