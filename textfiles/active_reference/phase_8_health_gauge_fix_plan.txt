  1. PROBLEM STATEMENT
===============================================================================

  The Project Health Gauge (and the entire "Status" card in the AI Prediction
  tab) shows "AT RISK" / "Moderate Risk" even when a project is perfectly on
  schedule (progress gap = 0%, actual progress meets planned progress).

===============================================================================
  2. ROOT CAUSE
===============================================================================

  In AIPredictionPresenter::presentNormal(), the overall risk is calculated
  as the MAX of TWO signals:

    1. currentGapRisk  — based on actual progress gap (gap=0 → 'Low') ✓
    2. nearTermRisk    — based on FORECAST model's predicted next-month
                         variance (even -1% variance → 'Moderate')

  When currentGapRisk='Low' and nearTermRisk='Moderate', the max is
  'Moderate', which displays as "AT RISK" — even though the project is
  on schedule right now.

  This affects:
    • Card header gradient and left border color (amber instead of green)
    • Gauge center overlay text ("AT RISK" / "Moderate Risk")
    • Schedule Status row in health overview ("AT RISK" in yellow)
    • Completion confidence shows "Medium" from regression fit quality
      (R²/obs), not schedule health confidence

===============================================================================
  3. CHOSEN DIRECTION
===============================================================================

  Separate concerns: health status shows CURRENT actual standing; prediction
  data shows FUTURE outlook. Industry practice (Earned Value Management /
  PMBOK) uses actual vs planned at current date for health, not forecasted
  performance.

  Key insight: progressGap already incorporates the time dimension naturally
  because expectedProgress is recalculated each page load using
  DateHelper::now(). As days pass, expected progress moves forward on the
  baseline S-curve, and if actual stays flat, the gap grows automatically.

===============================================================================
  4. IMPLEMENTATION STEPS
===============================================================================

  Fix 1 — AIPredictionPresenter.php (Risk Logic)
  -----------------------------------------------
  File: app/Services/AI/AIPredictionPresenter.php
  Location: presentNormal(), lines 475-501

  Change the overall risk determination to use ONLY currentGapRisk (the
  actual progress gap). The near-term forecast risk should NOT override
  the current actual status.

  Before:
    $overallRisk = max(currentGapRisk, nearTermRisk)

  After:
    $overallRisk = currentGapRisk

  Impact:
    • gap=0 → ON TRACK, green card ✓
    • gap=-8% (time passed, expected increased) → AT RISK, amber ✓
    • gap=-15%+ → AT RISK, red ✓
    • Forecast risk still available in assessment_data for the
      forecast table section (separate from health status)

  Fix 2 — AIPredictionPresenter.php (Confidence)
  -----------------------------------------------
  Location: presentNormal(), around lines 512-514 and return array

  Replace completion_confidence (regression fit quality) with an
  observation-count-based confidence metric using REAL observations only
  (excluding synthetic points from cross-project supplement).

  Logic:
    $realObs = $statistics['observation_count'] ?? 0;
    // Subtract synthetic points if in supplement mode
    $syntheticCount = $regression['synthetic_points_count'] ?? 0;
    $realObs = max(0, $realObs - $syntheticCount);

    $confidence = match(true) {
        $realObs >= 6 => 'High',
        $realObs >= 3 => 'Medium',
        default       => 'Low',
    };

  Impact:
    • ≥6 real observations → High confidence
    • 3-5 real observations → Medium confidence
    • <3 real observations → Low confidence
    • Hybrid data (1 real + 5 synthetic) → Low confidence (honest)

  Fix 3 — Update/Add Tests (if applicable)
  -----------------------------------------
  • Verify presentNormal() returns 'ON TRACK' when gap=0
  • Verify presentNormal() returns 'AT RISK' when gap > threshold
  • Verify confidence reflects real observation count, not augmented
