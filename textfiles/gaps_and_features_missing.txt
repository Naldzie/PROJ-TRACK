================================================================================
  VERSION 2 DEFERRED ITEMS (from Master Plan)
================================================================================

  These were intentionally deferred during V1 development and have
  existing documentation in the master plan. Start here if you want
  to extend the AI module.

  1. [V2] COMPLETION ESTIMATION
     - estimated_completion_date (projected completion date)
     - predicted_delay_days (estimated days beyond planned end date)
     - completion_confidence (derived from R² + remaining months ratio)
     - Solve regression equation for x when y = 100%
     - See: regression_implementation_master_plan_ver5.txt (V2 section)

  2. [V2] CROSS-PROJECT HISTORICAL REGRESSION
     - Use similar completed projects' progress as proxy for new projects
     - Addresses "Insufficient Data" fallback for projects with <2 observations
     - Similarity criteria: category, budget range, duration, contractor
     - See: regression_implementation_master_plan_ver5.txt (V2 section)

  3. [V2] MULTIPLE LINEAR REGRESSION (MLR)
     - Additional independent variables: budget utilization, issue density,
       contractor experience, seasonality, extension count
     - Matrix operations (Gaussian elimination or gradient descent)
     - AIPredictionService would auto-select SLR vs MLR based on data depth
     - See: regression_implementation_master_plan_ver5.txt (V2 section)

  4. [V2] S-CURVE REGRESSION OVERLAY
     - Overlay regression line (dashed) on the existing S-Curve chart
     - Forecast extension (dotted) continuing from current month to end
     - Highlighted variance region between predicted and planned
     - Tooltip: month, predicted %, planned %, variance
     - See: regression_implementation_master_plan_ver5.txt (V2 section)

  5. [V2] AI-POWERED RECOMMENDATIONS (Phase 7.6)
     - Replace rule-based RecommendationEngine with AI-generated recs
     - Prerequisites: issue severity field, contractor performance tracking
     - Same pattern as AIExplanationService (AI + static fallback)
     - See: phase7_implementation_plan.txt, ai_recommendation_data_gaps.txt

  6. [V2] FORECAST TABLE / RISK ASSESSMENT TABLE IN UI
     - Month-by-month forecast table (collapsible, hidden by default)
     - Or bandwidth/range forecasts (45-48% instead of 46.33%)
     - Deferred because linear increments mislead vs actual S-Curve
     - See: regression_implementation_master_plan_ver5.txt (V2 section)


================================================================================
  CONTRACTOR MANAGEMENT GAPS
================================================================================

  7. [GAP] CONTRACTOR PERFORMANCE TRACKING
     - No rating system, on-time delivery %, or quality score for contractors
     - Needed for: smarter AI recommendations, contractor evaluation,
       cross-project pattern detection
     - Potential fields: performance_rating, on_time_delivery_percentage,
       completed_projects_count, average_delay_days
     - Referenced as prerequisite in: ai_recommendation_data_gaps.txt

  8. [GAP] CONTRACTOR ANALYTICS DASHBOARD
     - Contractors currently see only a project list
     - No summary of all their projects: deadlines, compliance rate,
       upcoming inspections, completed vs ongoing
     - Could mirror admin dashboard but scoped to their assigned projects

  REPORTING & DATA EXPORT GAPS
================================================================================

  9. [GAP] REPORT GENERATION (PDF/EXCEL)
     - No way to export project reports for stakeholders
     - Missing: PDF of S-Curve chart, Excel of progress history,
       project summary document, extension history report

  10. [GAP] DATA EXPORT/IMPORT

      - No way to migrate data between systems


================================================================================
  NOTIFICATION & COMMUNICATION GAPS
================================================================================

  11. [GAP] IN-APP NOTIFICATION SYSTEM
      - Email notifications exist (welcome emails) but no in-app alerts
      - Missing: deadline reminders, overdue inspection alerts,
        extension approval/rejection notices, issue assignments

  12. [GAP] AUDIT LOG UI FOR NON-ADMINS

================================================================================
  WORKFLOW & PRODUCTIVITY GAPS
================================================================================

  13. [GAP] PROJECT COMPARISON
      - No side-by-side comparison of multiple projects
      - Cannot compare: progress %, budget, timeline, risk levels
      - Useful for management reviews and portfolio oversight

  14. [GAP] BULK OPERATIONS
      - No batch archive, batch status update, or bulk progress recording
      - Each action is per-project, time-consuming for large portfolios

  15. [GAP] USER ACTIVITY SUMMARY
      - No per-user work statistics
      - Missing: how many inspections recorded, issues closed,
        extensions processed, documents uploaded by each user

  16. [GAP] PROJECT TEMPLATES
      - No reusable baseline schedule templates
      - Similar project types (e.g., classroom buildings) must
        re-enter the same S-Curve targets manually every time
