===============================================================================
  DECISIONS MADE DURING IMPLEMENTATION
===============================================================================

  1. Computation in ProjectDetailService (not controller):
     Following the architecture rule that controllers should remain
     lightweight, the shifted baseline computation lives in a new
     prepareForecastData() method on ProjectDetailService rather than
     inline in the controller.

  2. Average month constant (30.44 days):
     The shifted baseline uses msPerMonth = 30.44 * 86400 * 1000 for the
     horizontal displacement. This is consistent across both methods and
     avoids the complexity of variable-length month handling in the chart.

  3. Chart 2 placed between Chart 1 and Variance Trend:
     This keeps the Progress tab layout: first the current status chart,
     then the long-term outlook, then the supporting trend charts.

  4. Legend items hidden by default:
     Both the polynomial forecast legend (Chart 1) and SA/EAC legends
     (Chart 2) start with display:none and are shown dynamically by JS
     based on data availability.
