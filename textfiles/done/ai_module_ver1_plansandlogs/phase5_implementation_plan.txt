CONTEXT

Phase 1-4 completed. The AI prediction pipeline (RegressionDatasetBuilder →
LinearRegressionService → ForecastService → BaselineComparisonService →
ProjectAssessmentService → AIPredictionService → AIPredictionPresenter) is
fully wired into ProjectDetailService and delivers real regression-based data
to the blade view.

However, the blade (ai-prediction.blade.php) still uses the old mockup-
compatible layout. The new data keys (regression_info, forecast_data,
assessment_data, next_prediction) are delivered but invisible.

The AI prediction card is embedded in the Overview tab
(resources/views/projects/project_detail/components/tabs/overview.blade.php:210),
not in a separate tab.

KNOWN LIMITATIONS
-----------------
• Simple Linear Regression assumes linear trend — real S-curve projects show
  acceleration in middle phases. Forecast values (e.g., +1.33% next month) may
  appear too conservative compared to recent actual increases (6-9%/month).
• No forecast table or risk assessment table will be added — they would be
  misleading with S-curve data and consume too much space in the overview tab.
• Timeline visualization kept as-is (placeholder for now).
• estimated_completion and predicted_delay_days remain deferred to V2.
